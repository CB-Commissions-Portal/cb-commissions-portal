Studio Script Build — User Guide

Carte Blanche Production Portal  ·  Season 39

Overview

The Studio Script Build tab is where you construct, manage, and export the complete studio running order for each episode. It replaces the traditional paper-based run of show with a live, collaborative document that feeds directly into the Word studio script, the ROS PDF, and the VT list.

All changes are stored in real time to the cloud. Multiple users can view the same episode simultaneously, and the Last saved by indicator always shows who made the most recent save.

The tab is accessible to Editorial, Content, Director, Finance, and Operations roles, each with different levels of access. The full breakdown is in the Role Matrix at the bottom of this guide.

Who Has Access

RoleWhat they can do
Admin / Deputy Admin / EditorialFull access — add, edit, delete, reorder, number, and save items. All modal fields editable.
ContentScript text only — can open EDIT ITEM and edit the script field; cannot change slugs, sound, screen, CGEN, story title, durations, or item order.
DirectorFull modal edit — can open EDIT ITEM and edit all fields (script, slugs, sound, screen, CGEN, story title, camera block). Cannot add, delete, reorder items, or change durations on the landing page.
Finance / OperationsView only — can see the episode and run all exports, but cannot edit anything.

Selecting an Episode

When you open the Studio Script Build tab you land on the episode picker. Each tile shows the episode code (e.g. S39 EP 09), broadcast date, and a HAS RUN OF SHOW badge in green if a script has already been saved for that episode. Past broadcast episodes show a red "Broadcast" label.

Click any tile to open that episode. Once inside, the ◀ Episodes button in the top-left returns you to the picker at any time without losing any saved data.

Adding Items

The Add Item panel sits on the right side of the screen. It is visible only to Admin, Deputy Admin, and Editorial roles.

  1. Select an item type from the dropdown. Items are grouped by category: Fixed, Live, Insert, Cold Start, Up Next, Break.
  2. Click + Add Item. The new item is appended to the bottom of the running order.
  3. Click 💾 Save to commit the addition to the database.

Fixed items (Opening Logo, Bumper In/Out) are pre-loaded with their slug, source channel, and sound already set for the season. You do not need to edit them unless the season slug changes.

Inline Editing

The Content and Duration fields can be edited directly in the running order table — no need to open the modal.

  • Content — click any content cell and type. Use this for the story name, insert title, or any short description visible in the ROS PDF.
  • Duration — click the duration cell and enter the time as M:SS (e.g. 3:45) or H:MM:SS (e.g. 1:02:30). The cumulative Ep Duration column updates immediately as you type.

Note: Inline changes are not saved to the database until you click 💾 Save.

The EDIT ITEM Modal

Click ✎ EDIT ITEM on any row to open the full edit modal. The modal header shows the item type badge, item number, item label, and episode code so you always know exactly which item you are editing.

The modal is split into two panels:

Left Panel — Live Preview

Displays the item exactly as it will appear in the exported Word studio script, scaled to fit the panel. The active item is highlighted with a blue outline, and you can scroll within the preview to see the surrounding items for context.

Click ▶ EXECUTE to refresh the preview with any edits you have made in the right panel. You can edit, execute, and review as many times as you like before saving.

EXECUTE does not save. It only updates the preview pane. You must click Save Changes (bottom right of the modal) to commit your edits to the database.

Writing Scripts

The script field is available for Live, Cold Start, and Up Next items. It supports a simple markup language for presenter cue lines.

Cue Lines

Any line that ends with a colon (:) is treated as a speaker cue. Cue lines are:

  • Displayed bold and underlined in the Word studio script export
  • Excluded from the word count — only dialogue lines count toward the word total
GOVAN:
Good evening and welcome to Carte Blanche.

LOURENSA:
Tonight we investigate a story that has gripped the nation…

GOVAN:
But first…

Camera Cue Lines

A special form of cue line is used to mark camera shots. Write PRESENTER: CAM X (where X is the camera designation) on its own line:

GOVAN: CAM 3 JIB
Good evening and welcome to Carte Blanche.

LOURENSA: CAM 1
Tonight we investigate…

GOVAN: CAM 2
But first, let's talk about…

Camera cue lines are:

  • Displayed bold and underlined in the Word script (same as regular cue lines)
  • Excluded from the word count
  • Automatically detected and listed in the Camera Block section below the script in the edit modal

Camera designation format: CAM 1, CAM 2A, CAM 3 JIB, CAM3JIB — all are recognised. Multi-word designations like CAM 3 JIB are fully supported.

Word Count

Below the script textarea, two figures update live as you type:

  • Total words — count of all non-cue, non-camera-cue words in the script
  • ÷ 3 — a rough timing estimate: total words ÷ 3 ≈ approximate read time in seconds at broadcast pace

Camera Blocking

The Camera Block section appears automatically below the script whenever the script contains camera cue lines (PRESENTER: CAM X). It is available for Live, Cold Start, and Up Next items.

How It Works

Every camera cue line in the script generates a row in the Camera Block. Rows appear in the exact order the cues appear in the script — if the same camera appears three times, it appears three times as separate rows.

Each row shows the camera designation (e.g. CAM 3 JIB) in a purple badge, and a text input where the director can enter a shot description:

  • Camera badge (purple) — the camera designation as read from the script, shown in uppercase
  • Shot description — free-text field for the shot type, framing, or movement (e.g. MWS into 2SHOT + screen between)

The Camera Block updates live. As you add or change camera cue lines in the script, the block below refreshes automatically. Existing shot descriptions are preserved when lines are edited — they are only cleared if the corresponding cue is removed entirely.

Camera Blocking in the Word Export

In the exported Word studio script, camera blocking information appears in the PRODUCTION column (column 2), below the Screen / Slug / CGEN / Story Title entries for each item. Each camera cue is listed with its shot description directly beneath it, in the order the cues appear in the script in column 4.

This means the director can read across the page: the camera cue in column 4 (script) corresponds to the shot description in column 2 (production) at the same position in the reading order.

Alignment note: True line-for-line alignment between the camera descriptions in column 2 and the cue lines in column 4 is not achievable in a fixed-column Word table, as it depends on text wrapping. The descriptions are listed in the same order as the cues, which gives the director a consistent cross-reference when reading the script.

Slugs & Sources

A slug is the technical playout identifier for a piece of media (e.g. CB2026_OPENING_LINK). Each item can carry one or more slugs, each with an optional source channel.

Managing Slugs

  • Click ＋ Add Slug to add a second (or third) slug to the same item
  • Click Remove next to any slug row to delete that slug
  • The source channel dropdown next to each slug sets which channel the media plays from
  • Slugs appear highlighted in lumo green in the Word studio script export
  • The VT List export uses the first slug assigned to each item

Audio Options — Cold Start & Up Next

For Cold Start and Up Next items, two additional audio flags are available in the EDIT ITEM modal:

FlagWhat it meansBadge shown in table
UPSOUNDThe clip plays with its natural/location audio — the presenter mic or studio audio rises up with the clipUPS
VOICE OVERThe presenter reads a voice-over track across the clipVO

When either flag is ticked, the corresponding badge (UPS or VO) appears below the content field in the running order table, giving a quick visual reference without opening the modal.

Both flags can be active on the same item simultaneously (e.g. upsound for a brief moment before a voice-over begins).

Screen, CGEN & Story Title

These three fields are available for all item types (except Break) and feed directly into the PRODUCTION column of the Word studio script export.

FieldWhat it's used for
ScreenText to be displayed on the studio screen / video wall during this item (e.g. BLUE, BLUE + LOGO)
CGENCharacter Generator text — lower-third names, titles, or on-screen graphics. Each name or line on its own line in the textarea.
Story TitleThe on-screen story title or segment heading as it appears in the broadcast

Multi-line CGEN and Story Title

If you enter more than one line in any of these fields, each line gets its own labelled entry in the Word export. For example, if CGEN contains:

Govan Whittles
Lourensa Eckard

…the export shows:

CGEN:
Govan Whittles

CGEN:
Lourensa Eckard

This makes it unambiguous which label applies to which name, especially when multiple names share the same field.

Word Export Order (Production Column)

Fields appear in the PRODUCTION column in this priority order:

  1. Screen
  2. Slug(s) — highlighted in lumo green
  3. CGEN
  4. Story Title
  5. Camera Blocking (if any camera cues in script)

Out Words

The Out Words field is available for Insert items only. It records the last words spoken or heard at the tail of the insert — the line the director uses as a cue to know the clip is ending and the studio is coming back live.

Out words appear in the DESCRIPTION column of the Word export, directly below the item label and content, formatted as OUT WORDS: followed by the text.

Reordering & Deleting Items

Reordering

Use the ▲ and ▼ buttons on the left side of each row to move items up or down one position. The top button is disabled when the item is already at the top; the bottom button is disabled when it is already at the bottom.

After reordering, regenerate item numbers using the # Numbers button — numbers do not update automatically when you move items.

Deleting

Click the ✕ button on any row to remove the item immediately from the running order. Item numbers are not automatically adjusted on deletion — regenerate them using # Numbers after deleting.

Deletions are not reversible once you click 💾 Save. If you accidentally delete an item, do not save — refresh the page instead to reload the last saved version.

Item Numbers

Click # Numbers in the header bar to assign sequential numbers (1, 2, 3…) to all items in the current running order. Commercial Breaks are always excluded from numbering.

Always regenerate item numbers after:

  • Adding new items
  • Deleting items
  • Reordering items

Item numbers appear in the running order table, the ITEM column of the Word export, and the VT List.

Export Options

All exports are available to every role that can access the Studio Script Build tab, including view-only roles. Exports always reflect the most recently saved version of the script.

Studio Script (Word)

The primary studio document, downloaded as a .doc file (opens in Microsoft Word or compatible apps). The document is formatted for print, with a header, footer, and a five-column table.

ColumnContentsWidth
ITEMSequential item number4%
PRODUCTION Screen (labelled, one line per entry) → Slug(s) in lumo green → CGEN (labelled) → Story Title (labelled) → Camera blocking (camera designation + shot description, in script order) 22%
SOUNDSound designation (A, B, COLD START, etc.)11%
DESCRIPTION Item label (bold underlined) → Content → Out Words (Inserts only, labelled) → Script: regular cue lines (bold underlined), camera cue lines (bold underlined), dialogue text 56%
DURItem duration in MM:SS format (monospace font)7%

Fixed, Insert, Cold Start, Up Next, and Break items have a grey background row. Live items have a white background. The active item is highlighted with a blue outline when using the Preview Script function.

Use 👁 Preview Script before downloading the Word file. The preview is identical to the export and lets you spot formatting issues without generating a download.

Footer

Every page of the Word export has a footer containing the episode details (CARTE BLANCHE | SEASON 39 | EPISODE XX | TX: DATE) on the left, and the page number on the right.

ROS PDF

A condensed A4 landscape running order — designed for a quick overview in the control room or the director's desk. The PDF contains:

  • Episode header (season, episode number, TX date)
  • For each item: item label, content, item duration, cumulative episode duration
  • Row colours match the item type colour coding (blue for live, orange/gold for inserts, etc.)

The PDF does not include scripts, slugs, sound, or any other detail — use the Word export for the full script.

VT List

A slug sheet for the edit suite and playout team. Lists only items that have at least one slug assigned — items without any slugs are skipped entirely.

ColumnContents
Item #Item number (from the # Numbers generator)
SlugSlug name in orange/gold text
SourceSource channel (A / B / C / D / BLUE) in green, or — if no source is set

If an item is missing from the VT List, it means no slug has been assigned to it. Open EDIT ITEM for that row and add a slug and source before exporting.

Tips & Shortcuts

  • Fixed items (Opening Logo, Bumper In/Out, Closing Credits) have slugs, source, and sound pre-assigned for the season. Their durations are locked and cannot be changed.
  • Cue lines — any script line ending with : — appear as bold underlined speaker headings in the Word export and are excluded from the word count. This includes both regular cues (GOVAN:) and camera cues (GOVAN: CAM 3 JIB).
  • The ÷ 3 figure is a rough timing guide: total words ÷ 3 ≈ approximate read time in seconds at broadcast pace.
  • ▶ EXECUTE in the Edit modal only refreshes the preview pane — it does not save. Always click Save Changes to commit edits.
  • Always regenerate # Numbers after any structural change (add, delete, reorder). Numbers do not update automatically.
  • The Camera Block refreshes automatically as you edit the script. Shot descriptions are preserved when you tweak a cue line — they are only cleared if you remove the cue entirely.
  • Camera blocking in the Word export appears in the PRODUCTION column (column 2) in script order. Read across the page: column 4 shows the cue, column 2 shows what the camera should be doing at that moment.
  • The VT List only includes items that have at least one slug. If an item is missing, check that it has a slug and source set in EDIT ITEM.
  • The Ep Duration ↑ column counts downward from each item to the end of the episode — the top row shows the full programme duration. Use this to quickly identify where time can be cut or added.
  • Click 👁 Preview Script before downloading the Word file to do a final visual check without generating a download.
  • If you add CGEN entries with multiple names, put each name on its own line — the export will label each line separately, making it clear which graphic applies to which name.
  • UP NEXT VISUAL vs UP NEXT UPSOUND: use Visual when the presenter is off-screen; use Upsound when the presenter mic is live during the clip.
