Studio Script Build — User Guide

Carte Blanche Production Portal  ·  Season 39

Overview

The Studio Script Build tab is where you construct, manage, and export the complete studio running order for each episode. It replaces the traditional paper-based run of show with a live, collaborative document that feeds directly into the Word studio script, the ROS PDF, and the VT list.

All changes are stored in real time to the cloud. Multiple users can view the same episode simultaneously, and the Last saved by indicator always shows who made the most recent save.

Who Has Access

RoleWhat they can do
Admin / Deputy Admin / EditorialFull access — add, edit, delete, reorder, number, and save items

DirectorDirector's Notes only — can open EDIT ITEM and edit the Director's Notes block; cannot change anything else
Finance / OperationsView only

Selecting an Episode

When you open the Studio Script Build tab you land on the episode picker. Each tile shows the episode code, broadcast date, and a HAS RUN OF SHOW badge if a script has already been saved. Past broadcast episodes appear in red.

Click any tile to open that episode. Once inside, the ◀ Episodes button in the top-left takes you back to the picker at any time.

Adding Items

The Add Item panel sits on the right side of the screen (visible to Admin / Editorial only).

  1. Select an item type from the dropdown. Items are grouped by category (Fixed, Live, Insert, Cold Start, Up Next, Break).
  2. Click + Add Item. The item is appended to the bottom of the running order.

Fixed items (Opening Logo, Bumper In, Bumper Out) are pre-loaded with their slug, source, and sound already set — you do not need to edit these unless something changes for the season.

Inline Editing

The Content and Duration fields can be edited directly in the table without opening the modal — click into any field and start typing.

  • Content — free text describing the item (e.g. story name, insert title)
  • Duration — enter as M:SS (e.g. 3:45) or H:MM:SS (e.g. 1:02:30). The cumulative episode duration column updates immediately.

Note: Inline changes are not saved to the database until you click 💾 Save.

The EDIT ITEM Modal

Click ✎ EDIT ITEM on any row to open the full edit modal. It is split into two panels:

Left Panel — Live Preview

Shows the item exactly as it will appear in the exported Word document, scaled to fit. The active item is highlighted with a blue outline so you can see it in context of the full script above and below.

Click ▶ EXECUTE to refresh the preview with your current unsaved edits. You can keep editing and keep clicking EXECUTE until you are satisfied, then click Save Changes.

EXECUTE does not save. It only updates the preview. You must click Save Changes to commit edits to the database.

Writing Scripts

The script field supports a simple markup for cue lines. Any line ending with a colon (:) is treated as a speaker cue — it appears bold and underlined in the Word export and is excluded from the word count.

PRESENTER A:
Good evening and welcome to Carte Blanche.

PRESENTER B:
Tonight we investigate a story that has gripped the nation…

Below the script textarea, two figures update live as you type:

  • Total words — count of all non-cue words
  • ÷ 3 — a rough timing estimate (words ÷ 3 = approximate seconds at broadcast pace)

Slugs & Sources

A slug is the technical identifier for a piece of media (e.g. CB2026_OPENING_LINK). Each item can carry one or more slugs, each with an optional source channel.

Source channels

SourceMeaning
APrimary playout channel
BSecondary channel
CTertiary channel
DFourth channel
BLUELive/Blue channel

To manage slugs in the Edit modal:

  • Click ＋ Add Slug to add a second slug to the same item
  • Click Remove next to any slug row to delete it
  • The first slug is used in the VT List export

Slugs appear highlighted in lumo green in the Word studio script export.

Director's Notes

The Director's Notes section (separated by an orange border at the bottom of the EDIT ITEM modal) is for blocking notes, camera calls, staging directions, and any technical cues for the studio director.

  • Visible to all roles
  • Editable by Admin and Director roles only
  • Appears in the PRODUCTION column of the Word export in grey italic text below the slug
  • No character limit

Reordering & Deleting Items

Reordering

Use the ▲ and ▼ buttons on the left of each row to move items up or down. The buttons are disabled when an item is at the top or bottom of the list.

After reordering, regenerate item numbers using the # Numbers button — numbers do not update automatically when you move items.

Deleting

Click the ✕ button on any row to remove the item. Item numbers are cleared on deletion — regenerate them with # Numbers afterwards.

Item Numbers

Click # Numbers in the header bar to assign sequential numbers (1, 2, 3…) to all items. Commercial Breaks are always excluded from numbering.

Regenerate item numbers after:

  • Adding new items
  • Deleting items
  • Reordering items

Export Options

All exports automatically flush any unsaved inline edits before generating the document, so the output always reflects the current state of the screen.

ROS PDF

A condensed A4 landscape overview — designed for the control room and director's desk. Contains item label, content, item duration, and cumulative episode duration. Row colours match the type colour coding (blue for live, orange for inserts, etc.).

VT List

A slug sheet for the edit suite. Lists only items that have slugs assigned — items without any slugs are skipped.

ColumnContents
Item #Item number
SlugSlug name in orange/gold

If an item has no slug, it will not appear on the VT List. Check that all playout items have slugs and sources assigned before exporting.

Tips & Shortcuts

  • Fixed items (Opening Logo, Bumper In/Out, Closing Credits) have slugs, source, and sound pre-assigned for the season. They are locked — you do not need to edit them unless the season slug changes.
  • Cue lines — any script line ending with : — are formatted as bold underlined speaker headings in the Word export and are excluded from the word count.
  • The ÷ 3 figure is a rough timing guide: total words divided by 3 gives an approximate read time in seconds at broadcast pace.
  • ▶ EXECUTE in the Edit modal only refreshes the preview — it does not save. Always click Save Changes to commit.
  • Always regenerate # Numbers after any structural change (add, delete, reorder). Numbers do not update automatically.
  • The VT List only includes items that have at least one slug. If an item is missing from the VT List, check that it has a slug assigned in EDIT ITEM.
  • The Ep Duration ↑ column counts from each item down to the end of the episode — the top row shows the full episode total. This helps identify where time can be trimmed.
  • Click 👁 Preview Script before downloading the Word file to do a final check without generating a download.
