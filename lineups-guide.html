Line-Ups — User Guide

Carte Blanche Production Portal  ·  Season 39

Overview

The Line-Ups tab shows the planned broadcast content for every episode of the season. Each episode has its own card listing the assigned Director, on-air Anchors, and all commission inserts that are scheduled for that episode — along with each insert's duration, presenter VO, and producer.

The tab gives the whole production team a single, always-current view of what is going to air in each episode. Content is pulled automatically from the Commission List, so there is no manual data entry required to see the planned schedule — you only need to actively manage the line-up when you want to add, remove, or reorder items.

All changes are stored in real time to the cloud.

Tab Layout

The tab is divided into two panels side by side:

  • Main panel (left) — the list of episode cards, one per episode in the season, sorted by episode number.
  • Inserts in Production panel (right, 280px) — a reference list of all active commissions that have not yet been broadcast. Use it as a quick reference when building line-ups.

At the top of the main panel the heading LINE-UPS · Season 39 is shown alongside a reminder that broadcast episodes appear in red and that a ✓ next to a duration means the insert has been delivered.

Episode Header

Every episode card starts with a clickable header bar. Click anywhere on the header to expand or collapse that episode's details.

All episodes are collapsed by default when you first open the tab. Click an episode header to open it.

Past Episodes

Episodes whose broadcast date has already passed are shown in a red theme throughout — the card background, header, text, and commission numbers all use red tones. The BROADCAST badge appears in the episode header.

Past episodes are locked — you cannot add or remove commissions, and the Director field becomes read-only. The line-up is preserved as a permanent record of what aired.

Auto-Population

The Line-Ups tab automatically pulls commissions into each episode based on the Broadcast Episode field set in the Commission List. You do not need to manually add commissions that have already been assigned an episode there — they will appear automatically.

The auto-population logic works as follows:

  1. Any active commission (not decommissioned) that has a story name and a broadcast episode number matching the current episode is included automatically.
  2. Items are ordered by the Broadcast Order field from the Commission List.
  3. If a commission was previously manually removed from a line-up, it is added to an exclusion list and will not be re-added automatically, even if it still has the episode number set in the Commission List.

Removed items stay removed. When you remove a commission from a line-up using the ✕ button, it is added to the exclusion list for that episode. It will not auto-reappear. If you want it back, use the Add Commission dropdown to re-add it manually.

Adding a Commission

Roles with edit access can manually add any active commission to any upcoming episode's line-up.

  1. Expand the episode card you want to edit.
  2. At the bottom of the content area, find the + Add commission… dropdown.
  3. The dropdown lists all active commissions that are not already in this episode, sorted by commission number. Each option shows the commission number, story name, and current duration.
  4. Select the commission you want to add. It is added to the line-up immediately and saved to the database.

Note: Adding a commission here does not change its Broadcast Episode in the Commission List. The line-up is managed independently. If the commission is assigned to a different episode in the Commission List, it may appear in both places.

Removing a Commission

To remove a commission from a line-up, click the ✕ button on the right side of that commission's row. The item is removed immediately and saved.

The removed commission is added to the episode's exclusion list so that auto-population does not add it back. If you later want it back in the episode, use the + Add commission… dropdown to re-add it manually.

The ✕ button is not available on broadcast episodes. Past line-ups are locked and cannot be edited.

Editing the Director

The Director field in each episode is a free-text input. Click into it and type the director's name. The field saves automatically after a short pause (800ms debounce) — there is no separate Save button required.

Autocomplete

As you type, the Director field offers autocomplete suggestions drawn from:

  • Director names already saved in other episodes
  • Studio crew assignments from the Studio Script Build tab
  • Registered user display names
  • Commission list personnel (presenter VO, DOP, CA, editor fields)

Up to 8 suggestions are shown in a dropdown. Use the arrow keys to navigate, Enter to select, or Escape to close without selecting.

Inserts in Production Panel

The right-hand panel shows a reference list of all active commissions that have not yet been broadcast. This gives you a quick overview of what content is in the pipeline when you are building or reviewing line-ups.

Each entry shows:

  • Commission number — with a LIC or IH badge where applicable
  • Story name
  • Presenter VO and Producer
  • Delivery date (in gold) — or "No delivery date" if not yet set
  • Duration — delivered duration if available, otherwise commissioned duration

Entries are colour-coded by type:

Border colourType
GreenLicensed (LIC)
GreyIn-House (IH)
GoldOriginal / commissioned

The Inserts in Production panel is read-only. It is a reference tool — use it to quickly check what content is available when deciding what to add to an episode. To act on a commission, use the episode card's + Add commission… dropdown.

Tips

  • All episodes collapse by default when you open the tab. Click a header to expand the episode you want to work on — this keeps the screen uncluttered when you have a full season loaded.
  • The Total duration in the episode header is the sum of all insert durations. Use it as a quick sanity check against your target episode length before broadcast.
  • A ✓ next to a duration means the delivered duration has been captured in Post Production. An item without ✓ is using the original commissioned duration — it may change once delivered.
  • Anchor names come from the Studio Script Build tab. If they show —, open the relevant Studio Script Build episode and enter the anchor/host names there.
  • The Inserts in Production sidebar never shows commissions that have already been broadcast — it is filtered to upcoming content only. Use it to see what is still available to schedule.
  • If a commission disappears from a line-up unexpectedly after you removed it, check that it was not also removed from the episode's exclusion list. Use the + Add commission… dropdown to re-add it if needed.
  • Past episodes are fully locked. No edits are possible once a broadcast date has passed. The line-up at that point is a permanent record.
